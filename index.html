Search Engine Optimization Architecture

Project Overview

The project will focus on the topic of search engine optimization or SEO. SEO is usually viewed as a marketing discipline whereas search engines are distributed data systems powered by automated web crawler relational entities, machine learning models, and document parsers.

My research will give a general overview of SEO architecture through an IT and data analytics lens. The main goal will be to understand how certain engines render, index, rank, and discover web content across the Internet by looking at some examples.

Key Terms

Organic Search
Non-paid search engine listings determined naturally by algorithm scoring rather than paid advertising auctions.
Web Crawler (Bot / Spider)
An automated bot deployed by search engines that systematically fetches and scans web pages to discover links and update database records.
Search Index
A large-scale distributed repository where collected webpages and metadata are categorized, parsed, and stored for rapid information retrieval.
SERP (Search Engine Results Page)
The list of URLs, snippets, and media elements returned to a user after submitting a specific keyword search query.
Canonical Tag
An HTML element placed in document headers that indicates the authoritative master version of duplicate or syndicated webpages.
