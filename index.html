Search Engine Optimization Architecture

Project Overview

The project will focus on the topic of search engine optimization or SEO. SEO is usually viewed as a marketing discipline whereas search engines are distributed data systems powered by automated web crawler relational entities, machine learning models, and document parsers.

My research will give a general overview of SEO architecture through an IT and data analytics lens. The main goal will be to understand how certain engines render, index, rank, and discover web content across the Internet by looking at some examples.

Key Terms

Organic Search:
These are the normal, unpaid listings on a results page that show up because the search algorithm calculated the page to be relevant, not because someone bought an ad slot.
Web Crawler (Bot / Spider):
An automated bot that follows links across the web to discover pages, read server status codes, and grab content to send back to the search database.
Search Index:
The backend database where search engines organize, parse, and store text, code, and media from crawled pages so results can be pulled up quickly during a query.
SERP (Search Engine Results Page):
The actual page shown to a user after typing a keyword query, containing blue links, snippets, images, or map packs.
Canonical Tag:
A small line of code put in the HTML head to tell crawlers which URL is the main authoritative version when multiple pages have duplicate or similar items, like dynamic inventory filters.
