Key Concepts

Crawl Budget

The crawl budget is a finite number of URLs a search engine bot crawls on a domain with a specific timeframe, modern search engine processes pages in two sections[cite: 6]. The first section is parsing HTML text and links[cite: 6]. The second is queuing the page to execute client side JavaScript and construct a final document object model or DOM[cite: 6].

Core Web Vitals

Core web vitals is a standardized set of user experience metrics to serve the official search ranking largest contentful paint measures loading speed by timing how long it takes for largest image to render[cite: 6]. Interaction to next paint is responsible for assessing responsiveness by measuring input latency during a session[cite: 6, 7]. Cumulative layout shift, quantifies stability by calculating shift score of unexpected DOM movements[cite: 7].

Canonicalization

Contact management systems and e-commerce platforms generate multiple URLs that display identical or near identical content due to URL parameters[cite: 7]. Canonicalization uses the tag in HTML head to declare which URL is the master version[cite: 7].

Semantic Search

Rather than relying on exact keyword string matching, modern search engines transform queries and documents into high dimensional vectors using natural language processing models[cite: 7]. This enables algorithms to calculate similarity between users' intent and documents' meaning[cite: 7].

Structured Data

Structured data is standardized machine readable meta data embedded into webpages HTML is commonly formatted in JSON developers defined page entities attributes and relationships, feeding the search engine knowledge graphs and unlocking enhanced visual SERP features[cite: 7].

Human Evaluators

Human evaluators assess whether the web content, demonstrates experience expertise, authoritativeness, and trustworthiness[cite: 7]. The human evaluations, calibrate machine, learning ranking systems for sectors such as finance data and healthcare[cite: 7].

Page Rank

Page rank models, the web as a directed mathematical graph viewing, webpages as notes and hyperlinks as edges, internal linking dictates, how crawlers and authority flow from landing pages to sub pages, contacts grouped into topic clusters, minimizing, click depth and eliminating unreachable pages[cite: 7].
